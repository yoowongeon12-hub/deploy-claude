================================================================================
수정 날짜: 2026-09-20

================================================================================
문제 설명
================================================================================

증상:
- "완료" 버튼 한 번 클릭 → 댓글이 2번 이상 생성됨
- 데이터베이스에도 중복 저장됨
- 특히 SPA 환경 (app.js)에서 심각함

근본 원인 (3가지):
1. 스크립트 재로드 시 전역 변수 초기화 → 이벤트 리스너 참조 손실
2. SPA에서 부분 렌더링 → 이벤트 리스너 누적
3. 사용자 더블 클릭 → 두 개의 비동기 요청 동시 실행

================================================================================
해결 방법 (3단계)
================================================================================

✅ 해결 1: 전역 상태를 window 객체에 저장
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

코드:
    if (!window.boardDetailState) {
        window.boardDetailState = {
            commentSubmitListener: null,
            editButtonListener: null,
            deleteButtonListener: null,
            isSubmittingComment: false,
            lastSubmitTime: 0
        };
    }

목적:
- 스크립트 재로드 후에도 상태 유지
- 이벤트 리스너 참조가 손실되지 않음
- removeEventListener()가 정확하게 작동

효과:
- 첫 방문: boardDetailState 생성
- 재방문: 기존 boardDetailState 재사용
- 이벤트 리스너를 정확하게 제거/재등록 가능

✅ 해결 2: removeEventListener()로 정확한 제거
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

코드:
    if (window.boardDetailState.commentSubmitListener) {
        btnCommentSubmit.removeEventListener('click',
            window.boardDetailState.commentSubmitListener);
    }

    window.boardDetailState.commentSubmitListener = submitComment;
    btnCommentSubmit.addEventListener('click',
        window.boardDetailState.commentSubmitListener);

목적:
- 기존 리스너를 정확한 함수 참조로 제거
- 새로 등록하기 전에 완전히 제거
- 중복 등록 불가능

효과:
- 매번 버튼을 클릭할 때마다 1개의 리스너만 작동
- 스크립트 재로드 후에도 안전함

✅ 해결 3: 더블 클릭 방지 (시간 기반)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

코드:
    // 방지 1: 이미 작성 중이면 무시
    if (window.boardDetailState.isSubmittingComment) {
        return;
    }

    // 방지 2: 마지막 제출로부터 0.5초 이내면 무시
    const now = Date.now();
    if (now - window.boardDetailState.lastSubmitTime < 500) {
        return;
    }

    // 제출 시간 업데이트
    window.boardDetailState.lastSubmitTime = now;

목적:
- 버튼 연속 클릭 방지
- 네트워크 느린 환경에서도 안전
- 사용자 실수 방지

효과:
- 0ms: 첫 클릭 → 요청 전송 ✓
- 50ms: 두 번째 클릭 → 무시됨 (500ms 미경과)
- 600ms: 세 번째 클릭 → 요청 전송 ✓
