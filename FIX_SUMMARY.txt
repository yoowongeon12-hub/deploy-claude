1. 댓글 중복 작성 버그 수정 ✅
================================================================================

문제:
- 게시판 상세보기에서 댓글 작성 시 댓글이 2번 생성되는 오류
- 데이터베이스에도 중복 저장됨

원인:
- initBoardDetail() 함수에서 페이지 로드 시마다 이벤트 리스너가 중복 등록됨
- 같은 엘리먼트에 여러 개의 addEventListener가 누적됨

해결책:
- replaceWith(cloneNode(true))를 사용하여 기존 엘리먼트와 이벤트 리스너 제거
- 새로운 엘리먼트에만 깨끗한 이벤트 리스너 등록
- 댓글 제출, 수정, 삭제 버튼 모두에 적용

수정 파일:
✓ js/board-detail.js (initBoardDetail 함수 수정)

- JSON: http://localhost:3000/api-docs/swagger.json

문서화된 엔드포인트:

게시글 API (Posts):
  - GET /api/posts (목록 조회)
  - POST /api/posts (글 작성)
  - GET /api/posts/{id} (상세보기)
  - PUT /api/posts/{id} (수정)
  - DELETE /api/posts/{id} (삭제)

댓글 API (Comments):
  - GET /api/posts/{postId}/comments (목록 조회)
  - POST /api/posts/{postId}/comments (작성)
  - PUT /api/posts/{postId}/comments/{commentId} (수정)
  - DELETE /api/posts/{postId}/comments/{commentId} (삭제)
